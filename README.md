# GymHabit
Gym workout tracker. React + React Router + Tailwind CSS.

## Run
    npm install
    npm run dev

## How it was created
    npm create vite@latest gymhabit -- --template react
    npm install react-router-dom tailwindcss @tailwindcss/vite

## Deploy (Vercel / Netlify)
Build command: `npm run build`, output folder: `dist`.
`vercel.json` and `public/_redirects` keep page refreshes working on every route.
